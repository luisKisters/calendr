# Inspiration from other calendar apps

What the maintainer likes in other calendar apps, as input for design and feature work.

The screenshots are **not in this repo**. The repo is public and the screenshots show private
calendar data. They live on the maintainer's Mac in `~/Documents/horion-inspo/`, one folder per app,
with a README listing every file. Never add them (or any other screenshot of real calendar data) to the repo.

## Fantastical (`fantastical/`)

- **Agenda sidebar:** a list you can scroll through, grouped by day ("THURSDAY 19.11.26", "TODAY", "TOMORROW"),
  with weather per day. The active day is highlighted, the mini month marks the current week,
  and the selected event is highlighted in the list.
- **Natural-language input:** type the event as a sentence and it fills date, start and end live.
- Also captured: year view tinted by how busy each day is, quarter view, reminder popover.

## Morgen (`morgen/`)

- **Tasks with an earliest start and a due date**, plus importance and a time estimate.
- **Enter on a task moves it to the next day.**
- **Drag tasks into the calendar.**
- **Snappy, modern feel.**
- **Frames:** reserve a time slot in which tasks matching a filter get priority.
- **Routines:** repeating habits you check off in the calendar. Liked, but unsure how useful.

## Apple Calendar, macOS (`apple-calendar/`)

- **Glassy, blurry UI** for the create popovers (event and reminder).
- **Tasks (reminders) shown in the calendar grid.**
- **Invites inbox:** get notified when invited, and decline / maybe / accept right in the list. Liked most here.
- Creating a task was only "okay".

## Notion Calendar (`notion-calendar/`)

The app Horion is based on (see `SPEC.md`).

- **Show teammate calendar:** other people's calendars overlaid on yours. Liked most.
- **Time zone travel / extra time zones:** a second hour column for another time zone.
- **Scheduling links:** mark free ranges on the grid, get a link, a copyable text snippet and a booking page.
- **Menu bar agenda:** used often.
- **Copy conferencing link button:** used often. The old big **"Join meeting"** button was better than
  today's "Add meeting note".
- **Go to date** with natural language and short forms ("dec 25 2028", "in 4 weeks").
- **Google event types:** Focus time and Out of office are supported.
- **Editor placement:** right sidebar by default, or a popover next to the event.
- "Meet with…" in the sidebar: not that impressive.

## Google Calendar (`google-calendar/`)

Week view for comparison: solid bright fills, white titles, striped "maybe" events, today in a filled circle.

## Analog, analog.now (`analog/`)

Week view in a single hue with a 3 px left bar; a selected event turns solid. No liked features noted yet.
